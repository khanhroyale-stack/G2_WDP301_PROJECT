# Dự án Trao đổi đồ cũ

## Cách cài đặt cho Team:

1. Mở terminal và clone dự án: `git clone <link-github>`
2. Cài đặt Backend: `cd backend && npm install`
3. Cài đặt Frontend: `cd frontend && npm install`
4. Tạo file `back_end/.env` và thêm `MONGO_URI=<mongodb_connection_string>`

## Cách chạy dự án:

- Chạy Backend: Vào folder backend gõ `npm run dev` (cần cài nodemon)
- Chạy Frontend: Vào folder frontend gõ `npm run dev`
